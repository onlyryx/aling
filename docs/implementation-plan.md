架构与约束见 [architecture.md](architecture.md)。在空工作区直接初始化工程，
当前会话自主实施，不创建额外工作树、不连接真实账号、不部署。

1. 工程与核心：建立 Python 3.12 工程、配置校验、群权限、SQLite 开关与限频器。
   先写配置/权限/持久化/时间窗口测试，确认缺失功能失败，再实现并验证。
2. 服务：实现 OpenAI 兼容客户端、SSRF 防护网页客户端、扩展协议与主动发送入口。
   先写 HTTP 模拟测试、安全边界与关闭/冷却测试，再实现并验证。
3. 接入：注册 OneBot V11、服务生命周期、命令与明确 @ 群聊 matcher、隐私日志。
   先写事件和带令牌 WebSocket 模拟测试，再实现并验证；网络都用离线替身。
4. 交付：README、环境样例、Dockerfile/Compose、开源许可证与 CI。
   验证完整测试、代码检查、wheel/sdist、启动与容器配置；记录环境不能完成的检查。
