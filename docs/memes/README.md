# 本地表情包素材

阿零的 `/meme <关键词>` 只检索本地素材，不会联网搜索或下载图片。素材默认放在
`data/memes/`，Docker Compose 会以只读方式挂载到 bot 容器的 `/app/memes`；NapCat
无需共享这个目录，图片会通过 OneBot 的 base64 图片段发送。

在该目录创建 `manifest.json`，每项包含唯一资源 ID、简短描述、标签和相对路径：

```json
[
  {
    "id": "shrug-01",
    "description": "耸肩",
    "tags": ["无语", "不知道", "耸肩"],
    "path": "shrug.png"
  }
]
```

只添加自己制作或明确允许再分发的素材，并保留来源和许可信息。清单上限为 1 MB、
5000 项；图片只接受 PNG、JPEG、静态 WebP 或静态 GIF，单张最大 5 MB、最多 1200
万像素。解析到素材目录之外的路径（包括符号链接）都会被拒绝。仓库不提供默认图片素材。

首次使用前由超级用户运行 `/feature global meme on`，再由群主或管理员在目标群运行
`/feature meme on`。启用后无需重启 bot；群级开关不能覆盖超级用户关闭的全局开关。

## 面板整理素材（明确启用）

默认 `WEBUI_ENABLED=false`，基础 `compose.yaml` 继续只读挂载素材。启用时填写独立的
`WEBUI_ADMIN_TOKEN`（至少 43 个 URL 安全字符），指定已在 `SUPERUSERS` 中的
`WEBUI_OWNER_ID`，核对 `WEBUI_ORIGIN`。面板地址是 `/webui/`。

如需通过面板上传或编辑素材，先创建素材目录并授予容器非 root bot 用户写权限，再选择覆盖文件：

```sh
docker compose -f compose.yaml -f compose.webui.yaml up -d bot
```

此覆盖文件明确设置 `WEBUI_ENABLED=true`，仅将原 `/app/memes` 目标改为可写；数据库卷、
QQ 卷、端口、只读根文件系统及非 root 运行保持原设置。不使用覆盖文件时可以只读浏览；
页面显示不可写原因。`doctor` 也会离线诊断素材目录写权限，不会自动创建素材目录。

每次选择一张静态图片，上传后在“未整理素材”填写说明、标签、来源和许可。说明最多 200 字，
最多 32 个标签且各 80 字，来源和许可各最多 500 字。空说明不会进入机器人素材检索。
文件名由内容 SHA-256 和实际图片格式生成，客户端不能指定路径或文件名。

面板上传同时最多 2 个，每位部署者十分钟最多 30 次尝试，失败也计数。托管上传文件合计
最大 200 MB，包含已移除条目留下的文件；达到容量上限即暂停新增，不自动删除旧文件。
“移除索引”只删清单条目，永不删除原图，共享路径仍可用。需要释放容量时，请由部署者
离线检查引用后自行处理。面板不提供文件删除入口。

清单写入保留未知字段和未修改条目，以临时文件和原子替换发布，只保留上一版清单
`.manifest.previous.json`（最多 1 MB）。损坏或超限清单必须先人工修复，不能被空清单覆盖。
写入拒绝符号链接及路径穿越。将素材目录授予 bot 用户时，也应避免其他程序同时修改该目录。
